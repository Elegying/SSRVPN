# ADR-021：安装/卸载按精确映像名结束随包进程

日期：2026-09-22　状态：已接受（产品决策，部分取代 [ADR-020](020-installer-system-proxy-ownership.md) 与硬规则 #11 的旧边界）

## 背景

5.0.15 测试期的真实用户测试连续两次暴露同一类失败：目标用户是不具备排障能力的小白，
「换一个目录安装」或「机器上存在便携版/更旧副本」时，旧的停进程实现只能结束「路径精确
等于本次安装目录（及注册表上次安装目录）」的进程。任何第三目录中的副本仍持有全局单实例
互斥体 `Local\SSRVPN_Windows_SingleInstance`，安装器在改动系统代理前失败关闭，诊断阶段码为
`APP_INSTANCE_ACTIVE`，并把「退出所有 SSRVPN 窗口和托盘实例」留给用户自行处理——这
对该用户群体不可接受。

ADR-020 曾拒绝「以安装成功最高优先放开进程结束范围」的方案，当时的依据是：该提案不能
修复代理归属判定门本身的误判。这一前提仍然成立，但场景不同：本 ADR 处理的是
**所有 SSRVPN 自有副本都无法继续存活**前提下的停进程范围，而不是用结束进程去绕过代理
归属判定。5.0.14→5.0.15 的两轮实测（跨目录升级、`APP_INSTANCE_ACTIVE` 复现）证明
路径精确匹配在真实用户机器上无法收敛，维护者于 2026-09-22 明确做出产品决策：安装与
卸载必须自动结束所有同名进程，不再要求用户退出。

## 决策

1. 安装与卸载的停进程阶段按**精确映像名**匹配并结束本产品随包的三个可执行文件名：
   `ssrvpn_windows_app.exe`、`ssrvpn_windows.exe`、`mihomo.exe`，无论进程运行自
   哪个目录（当前安装目录、更旧安装目录、便携版或解压副本）。
2. 映像名清单是**封闭白名单**，由测试锁定；不得加入 Clash、OpenVPN、WireGuard、
   Tailscale、ZeroTier 等第三方通用名称。`mihomo.exe` 虽为开源内核通用名，仍按产品
   决策纳入按名结束范围；对恰好同名的其他软件进程的影响由覆盖提示向用户明示。
3. 逐 PID 的身份校验全部保留：CIM 枚举结果在结束前仍要经过活进程重开校验（进程名、
   会话、映像路径、创建时间），`Stop-VerifiedProcess` 的终止前再校验不变；陈旧 CIM 行、
   路径替换与 PID 复用依然不可能被盲目终止。
4. 旧副本的**文件**依旧不被搜索、迁移、合并、修改或删除（硬规则 #10 前半句不变）；
   本次只放宽「进程结束范围」。
5. ADR-020 的系统代理归属判定语义不变：恢复记录仍是归属的唯一证明，外来代理状态仍然
   原样保留。按名结束后已无任何存活的自有副本，不存在「在活着的副本之下改写 WinINet」
   的静默直连窗口。
6. 失败关闭出口保留：同名进程无法被结束（权限不足、受保护进程等）时仍以
   `IDENTITY_UNVERIFIED` / `APP_INSTANCE_ACTIVE` / `APP_STILL_RUNNING` 在改动系统
   代理与程序文件前停止，并提示重启 Windows。

## 结果

- 跨目录升级、便携版共存、回滚残留等场景下安装自动完成，不再向小白用户转嫁排障。
- 其他代理软件若恰好使用 `mihomo.exe` 作为内核文件名，其进程会在 SSRVN 安装/卸载期间
  被结束。该影响已由维护者于 2026-09-22 确认接受，并写入
  `installer/overwrite_notice.zh-CN.txt` 向用户披露。
- 硬规则 #8、#10、#11 的文本同步更新（编号与顺序不变）；ADR-020 追加取代说明。
- 运行时测试重写外来实例场景：同名副本必须被结束、外来命名的互斥体持有者仍必须失败
  关闭、第三方命名进程不得被触碰。

## 未采用的方案

### 保留路径精确匹配 + 注册表「上次安装目录」

5.0.15 测试版第 4 包引入，仍被第 6 次实测击穿：注册表 `InstallLocation` 只记录最后一
次成功安装，便携版、解压副本与回滚残留进程都不在其中。继续加枚举目录只会把判定门变成
不可枚举的猜测。

### 按可执行文件元数据（ProductName）校验后再按名结束

`mihomo.exe` 为 Go 构建，无可靠的版本资源可供校验；未签名构建也无法用签名作为身份
证明。元数据校验对最需要它的进程名不成立。

### 按父子进程关系推断归属

父 PID 可被复用，孤儿内核的父进程身份不可证明；在安装关键路径上引入竞态判定不可接受。
