# SSRVPN 功能列表

本清单描述当前仓库已实现的产品能力；安装包行为以对应正式 Release 为准。它用于产品介绍、回归测试、
维护审查和发版核对，不包含历史上已删除的功能、尚未合并的提案或仅存在于测试工具中的能力。

## 产品定位

SSRVPN 是基于 Mihomo 的 Android、macOS 和 Windows 开源客户端，不提供代理节点或订阅服务。
三端共享订阅解析、节点模型、路由策略、配置生成、更新校验和诊断语义，平台目录只实现系统
VPN、系统代理、TUN、托盘、安装器和安全存储等操作系统差异。

## 平台与分发

| 平台 | 支持范围 | 正式产物 | 连接方式 | 平台入口 |
| --- | --- | --- | --- | --- |
| Android | Android 7.0+、`arm64-v8a` | `SSRVPN.apk` | 系统 VPN | 前台通知、快捷设置磁贴 |
| macOS | macOS 11+、Apple M 系列 `arm64` | `SSRVPN.dmg` | 系统代理、TUN | 菜单栏、主窗口 |
| Windows | Windows 10 1507+、x64 | `SSRVPN_Setup.exe` | 系统代理、TUN | 系统托盘、主窗口、安全模式与诊断脚本 |

正式 Release 同时提供三个 SHA-256 文件和发布 provenance。macOS 为 ad-hoc、未公证分发，
Windows 安装器未签名；Android 使用固定自签名证书谱系支持覆盖升级。

## 首页与导航

- 三端统一使用“主页、订阅、设置”三页主导航。
- 首页显示未连接、正在连接、已连接、已连接（有提醒）、正在断开和连接异常状态，以及当前节点；连接方式和代理模式在从首页节点卡进入的节点选择页展示。
- 连接按钮支持开始、取消连接和断开，快速重复操作受状态代际保护。
- 首页显示当前 IPv4 出口信息；无效或 IPv6 响应不会作为公网地址展示。
- macOS/Windows 窗口失焦但仍可见时，流量和账号统计继续刷新；窗口最小化、隐藏或离开首页时暂停采样，恢复显示立即补采本地流量。切换焦点不清空速率基线。
- “使用教程”和“关于”从主页进入，使用统一透明毛玻璃弹窗、滚动内容和关闭操作。
- macOS 和 Windows 关闭窗口后可继续驻留菜单栏或系统托盘，并可重新显示或完全退出。

## 外观与特效

- 背景可选择内置壁纸、纯色或本地自定义图片，并单独设置玻璃效果质量等级。
- 内置壁纸默认静止：不请求任何一帧，也不带动其上所有玻璃卡片重新合成。设置页「外观」提供「动态背景」开关，仅对「壁纸」背景可用。
- 纯色与自定义背景本就不运行流动动画，开关对其禁用并说明原因；系统开启「减少动态效果」时同样禁用并说明，不静默否决用户选择。
- 关闭「动态背景」时壁纸停在当前相位而非跳回起点，重新开启从同一相位继续。

## 订阅管理

- 添加订阅 URL；首次没有节点时自动弹出导入引导。
- 支持合法 HTTP 与 HTTPS 订阅，界面和文档推荐使用 HTTPS。
- 添加单节点链接并立即写入本地节点缓存，不需要刷新其他远程订阅。
- 首次引导与订阅页共用导入逻辑；新订阅和引导中的重试只拉取该来源，无效端口或没有可运行节点的本地链接不保存。
- 支持单独刷新一个订阅或一次刷新全部订阅；当前连接节点的有效配置未变时保持连接，界面不提供订阅自动更新开关。
- 多订阅刷新分别提交成功来源、保留失败来源已有节点，并显示失败原因；全部失败不改变有效缓存。
- 保存订阅信息和最近成功更新时间；数据模型中的启用状态与自动更新字段用于兼容现有数据，不代表界面提供对应开关。
- 订阅卡片提供可见的编辑按钮，也保留 Android 长按、macOS/Windows 右键编辑，支持修改名称和链接。
- 只改订阅名称会更新显示分组，保留测速和连接；修改链接时仅更新该来源，失败则保留旧链接和节点，不覆盖其他来源的手工编辑。
- 删除订阅在本地缓存中移除对应来源，无需联网；去重节点保留其他有效来源，并防止并发刷新把已删除数据写回。
- 旧缓存按可证明的归属和本地节点内容恢复来源；旧版多来源去重只记录首个显示标签，因此这类节点保留为“历史缓存”，在剩余来源全部成功刷新后替换，避免离线删除时误删共享节点。
- 三端订阅页右上角统一提供带“运行日志”文字的诊断入口，窄窗口和大字号不退化为难以辨认的纯图标；节点选择页不再重复显示该入口。
- 下载流程包含超时、重试、取消、重定向、DNS 地址检查、响应大小和解析复杂度限制。
- 服务商拒绝默认 SSRVPN 标识或返回无法识别的成功内容时，按 SSRVPN、Clash Verge、v2rayN、Shadowrocket 顺序进行最多四种客户端标识协商；认证失败、地址失效和限流立即停止，兼容协商与网络重试共享六次逻辑请求预算。
- 刷新失败按来源保留最后一份可用节点，不用空结果覆盖失败来源；最终合并结果经过校验和原子缓存写入，元数据保存失败时回滚。订阅信息和节点缓存共用恢复记录，写入中途退出后，下次启动恢复上一份完整数据。

## 支持的订阅与节点格式

支持解析 Mihomo/Clash YAML、Base64 文本和逐行 URI 列表。当前解析器覆盖：

- Shadowsocks（SS）与 ShadowsocksR（SSR）；SS 支持 SIP002 插件参数及旧式完整 Base64 分享链接
- VMess
- VLESS，包括 TLS、Reality、WebSocket、HTTP/H2、gRPC 和 XHTTP 等常见参数
- Trojan
- Hysteria 与 Hysteria2；HY2 分享链接支持默认 443 端口和地址中的端口跳跃范围
- TUIC
- AnyTLS
- Snell
- SOCKS、SOCKS5、SOCKS5h、SOCKS5 over TLS
- HTTP 与 HTTPS 代理节点

订阅内容仍需满足 Mihomo 支持范围和项目的字段、地址、端口、节点数量及数据大小限制；
“能够解析”不等于服务端、协议组合或目标网络一定可用。

SS 插件按三端随包内核的共同支持范围接收：obfs（含分享链接中的 simple-obfs/obfs-local
别名）、v2ray-plugin、gost-plugin、shadow-tls、restls、kcptun。未知或仅部分内核支持的
插件（如 JLS）不导入，以免内核静默取消插件传输。HY2 的 mport/ports 和 hop-interval
查询参数同样检查合法范围；无效分享链接会被逐条跳过。

HTTP/HTTPS 分享链接支持显式标准端口 80/443。直接输入的匿名标准端口网址仍按订阅地址处理；
这类无认证代理可从 URI 列表或 YAML 导入，带认证的标准端口代理可以作为单节点链接输入。

## 节点管理与选择

- 按订阅筛选当前显示的节点。
- 在订阅默认顺序和当前页面延迟升序之间即时切换，不改写源订阅。
- 批量测试节点延迟，并支持超时、取消、并发上限和陈旧结果隔离。
- 三端保存上次测速结果及时间，重新启动后直接显示已有记录，不自动重复测速。名称、协议、服务器或端口改变后不套用旧记录；再次测速会更新数值及失败状态。
- 延迟使用节点服务器与端口的 TCP Socket 建连耗时，结果只代表该次端口可达性；名称含“私家车”的节点按既定产品策略不展示实测值，而是显示 24–39 ms 的随机延迟，该显示值参与排序与颜色分级（超时与失败值不受影响）。
- 超时节点置底并弱化显示，但延迟不作为选择闸门：超时、失败或未测速的节点在已连接状态下同样可以选中，也可进入编辑页检查。
- 未连接时可离线预选下次连接节点；连接后可直接切换当前可用节点。
- 记忆最近一次选择的节点，重新启动和 Android 快捷磁贴连接时继续使用。
- 节点编辑页按协议展示可编辑字段，并在保存前校验名称、地址、端口和协议参数。
- 长节点名称保留有辨识度的后缀，国旗和状态不只依赖颜色表达。

## 连接方式与代理模式

- 界面只提供“智能”和“全局”两个代理模式。
- “智能”按“用户强制代理 → 用户强制直连 → 公网 IP 探测域名代理 → 私网安全 → 海外/AI/流媒体代理 → GFW 代理 → 国内企业域名 → 国内企业 ASN → CN 域名/IP 直连 → 未知流量代理”的顺序运行。
- “全局”仍让所有流量走用户选中的代理节点。
- 用户可维护有限数量的强制代理或强制直连域名/IP；同一目标冲突时代理优先，自动规则不能覆盖用户选择。
- 海外与国内企业规则随客户端内置并持久化；连接成功两分钟后只读取极小版本描述，版本相同不下载，发现更高版本才校验清单和下载变化内容。全部内容验证成功后才原子保存规则文件并最后提交版本，下次连接整体启用；当前连接继续使用原版本，任一步失败都保留有效缓存且不阻断连接。
- Android 使用系统 VPN 与前台服务接管 IPv4 / IPv6 流量；对经过人工审查的明确国内应用执行系统级直连，“智能”与“全局”两种模式都保留该名单，全局模式其余流量交给 GLOBAL。通用浏览器和海外应用始终保留在 VPN 内。
- macOS 和 Windows 可在系统代理与 TUN 之间选择：系统代理适合遵循系统设置的应用，TUN
  适合游戏和不读取系统代理的程序。
- 桌面端支持 mixed、SOCKS 和本地控制 API 端口；冲突时可在安全边界内选择临时端口并显示变化。
- TUN 配置支持 Mihomo 的 `gvisor`、`system` 和 `mixed` 栈值，非法旧设置回退到安全默认值。
- 三端核心和 DNS 启用 IPv6，TUN 接管 IPv4 / IPv6 并沿用相同分流规则。代理域名目标优先尝试 IPv4，并在有限预算内尝试备用地址；IPv6-only 代理目标需要节点具备 IPv6 出口，不会在代理失败后自动改为直连。设计与限制见 [双栈分流说明](decisions/019-dual-stack-routing.md)。

## 连接状态、健康与恢复

- 建连阶段校验核心进程、受认证本地 API、节点选择及目标平台 VPN/代理/TUN 是否真正就绪。
- “连接中”可取消，取消后的迟到结果不会重新发布已连接状态。
- 连接后的核心存活、本地代理/TUN 所有权和外部可达性分别观察。
- 外部网站短时不可达只显示建议性提醒，不会自动断开、重启核心或切换节点；三端都在连接期间周期观察外部可达性，Android 由独立定时器承担，桌面端在物理网络变化时立即重新观察。
- 持续性失败才会自动恢复：需连续多次失败且超过宽限窗口（3 秒轮询 × 连续 3 次失败，约 9 秒落地；宽限严格小于采样已覆盖的跨度，因此不受定时器抖动影响，不会漂到下一个周期），单次瞬时失败不重启；核心进程已退出（本地 API 端口不再监听）时走快速判定。恢复期间首页显示持续的进行中状态。
- 节点切换、刷新、恢复和健康探针都绑定连接与路由代际，旧结果不能污染新会话。
- Android 核心异常退出最多进行两次受控恢复，并通过应用状态、通知和快捷磁贴同步结果。
- macOS/Windows 在异常退出、断开、退出和下次登录恢复中，仅处理仍能证明属于 SSRVPN 的
  核心、系统代理、TUN、DNS 和恢复记录。
- 系统代理被用户或其他软件修改后，SSRVPN 不会用旧快照覆盖新的外部设置。

## 更新功能

- 节点连接成功后后台检查正式 GitHub Release；未连接启动不检查更新。
- 检测到新版后在底部版本号旁显示持续可见的“发现新版本 立即更新”入口。
- 用户点击后才打开更新页；下载显示进度并支持取消。
- 只接受当前平台规范资产、匹配版本和同名 SHA-256，下载完成后再次校验摘要。
- Android 下载已验证 APK 后进入系统安装确认流程。
- macOS 下载已验证 DMG，并在打开前尝试安全断开当前连接。
- Windows 将已验证安装器保存到当前用户真实桌面，提示用户手动安装，不自动执行安装器。
- 由受支持客户端内置更新器下载并授权的 Windows 安装包，在安装成功后自动清理；取消、失败、
  手动下载或身份不匹配的文件保留。

## 日志、诊断与故障恢复

- 内置统一诊断页，默认展示一句话结论、稳定错误编号、中文检查结果、用户可执行建议和按本地时间整理的运行记录。
- 最近运行记录会隐藏内部事件名、会话编号、路径和重复核心信息，并用“连接、智能规则、系统代理”等类别说明发生了什么；完整脱敏原文只在默认收起的“技术明细”中提供。
- 支持主动复制诊断；复制成功需要回读内容与脱敏报告一致。
- 日志和诊断限长，自动处理订阅 URL、认证信息、密码、用户路径和公网地址等敏感内容。
- 本地崩溃报告包含应用版本和稳定指纹，启动后可提示用户查看或处理。
- 不自动上传日志、崩溃报告、订阅、节点或使用数据。
- Windows 提供 `SSRVPN_Diag.bat` 检查安装载荷与核心启动，提供 `ssrvpn_safe_mode.bat`
  跳过托盘、旧窗口位置和核心自动初始化以处理启动异常。

## 平台专项能力

### Android

- 原生 `VpnService`、前台常驻通知和连接状态同步。
- 快捷设置磁贴连接/断开并复用最近节点。
- 熄屏暂停流量数字周期刷新，亮屏恢复；状态或节点变化立即更新，相同通知内容不重复发布。
- 逐 socket `protect()` 避免 Mihomo 出站再次进入自身 VPN。
- 内嵌核心资产带固定源码与构建记录，并检查 16 KiB ELF LOAD 对齐。

### macOS

- 系统代理快照、所有权核验、恢复事务和菜单栏控制。
- TUN 使用按次管理员授权的临时 root runner；应用退出或连接失败后收口核心、路由、DNS 和暂存文件。
- 单实例租约、窗口恢复、核心 PID/创建代际记录和异常退出保护。
- Release 权限最小化，不包含调试、JIT、未签名可执行内存或禁用库校验 entitlement。

### Windows

- 外层启动器、单实例控制、系统托盘、窗口恢复和崩溃转储管理。
- 系统代理快照、恢复日志、RunOnce 异常恢复和仅关闭不可达自有端点的保守修复。
- TUN 运行身份、进程树、Job Object 和安全停止校验。
- Inno Setup 每用户安装、覆盖升级、数据保留、安装失败回滚和真实安装/卸载 smoke。
- 应用内更新安装包的专属授权、成功后自动清理与失败保留。

## 安全与供应链能力

- 本地 Mihomo API 使用随机 secret 认证，普通设置文件不保存 secret。
- Android 使用安全存储，Windows 使用当前用户 DPAPI，macOS 使用独立权限文件。
- 订阅和更新网络请求执行 TLS、证书、重定向、地址、大小、超时和来源校验。
- GitHub Actions 第三方依赖固定完整提交 SHA；PR 执行 Dependency Review、CodeQL、秘密扫描和许可证检查。
- 发布资产包含 SHA-256、provenance 和 GitHub Attestations，并与不可变 tag 和精确提交绑定。
- Mihomo、Android 核心和 GeoIP 带精确版本、源码方向、许可证与构建来源记录。

## 工程与维护能力

- Monorepo 统一管理三端客户端、共享包、原生桥接、安装器、测试和发布脚本。
- `make verify` 聚合格式、静态分析、资源、秘密、性能、共享/平台测试、原生测试和覆盖率门槛。
- 高风险生命周期和安装事务有职责边界、规模护栏及针对失败路径的回归。
- `Prepare Release` 自动完成版本核对、固定核心资产校验、精确 `main` CI、不可变 tag 和 Release 调度；GeoIP 更新独立为显式手动维护任务。
- Release workflow 构建三端资产，验证来源和摘要，同步 OSS，并在失败时执行有界恢复或回滚。

## 明确不提供的能力

- 不提供节点、订阅账号或代理服务。
- 不支持 iOS、Linux GUI、Intel Mac、Windows ARM 或非 `arm64-v8a` Android 正式包。
- 不提供 IPv6 与 IPv4 之间的地址转换（NAT64/DNS64）：IPv6-only 目标需要所选节点自身具备 IPv6 出口，失败时不会回退为直连。
- 不提供流媒体/服务解锁测试页面或隐藏检测入口。
- 不发布 Windows 便携 ZIP，不提供 macOS/Windows 付费发布者签名。
- 不自动上传遥测、日志、崩溃报告或用户配置，也不提供云同步。
