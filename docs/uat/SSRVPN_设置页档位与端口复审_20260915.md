# 设置页档位与端口复审（2026-09-15）

## 本轮修改

- 自定义图片说明与按钮之间增加 12 像素间隔，说明行高为 1.5；窄屏允许自然换行。
- 新增深蓝（#071A3A）与纯黑（#000000）背景，共七种纯色。颜色标签改为穷尽枚举匹配，旧自定义图片设置保持兼容，所有颜色均可保存恢复。
- 统一遗留玻璃容器和 FrostedPanel 到共享材质入口，取消独立按像素选择模糊强度的逻辑。当前主界面已使用共享材质；保留兼容包装避免以后重新引入不一致。
- 无、低档不启用玻璃 shader、背景模糊和连接按钮装饰光晕；中档采用二维材质，高档在支持的设备使用共享背景纹理和折射。文字和图标保持清晰前景，不额外嵌套玻璃。
- 中档二维渲染器不自动归一化高级材质参数，因此显式使用厚度 12、光照 0.51；高档仍为厚度 30、光照 0.85。导航与卡片使用同一个参数解析入口。
- 高对比度、减少动态效果等系统设置继续优先作用；旧硬件不支持高档渲染时使用库的兼容回退，不能保证不同 GPU 的视觉完全相同。

## 端口行为与修复

保存代理端口时检查 1024–65535 范围及与 SOCKS、API 端口的重复。保存的是首选端口，下次在应用内连接生效，当前连接不被立即中断。

启动时检查 TCP/UDP 与可用的 IPv4/IPv6 回环地址。首选端口被占用时，先尝试后续最多 50 个端口，再有限次尝试系统分配的候选；三个运行端口避免互相重复。调整只用于本次运行，设置页显示实际端口，日志记录调整，重连时重新尝试首选端口。不结束占用端口的其他进程。

修复了 Android 模式/手动规则和桌面手动规则更新时，将持久化首选端口提前覆盖到运行配置的问题。新增共享 updateLiveSettings，在连接重新准备之前保留当前代理、SOCKS、API 端口和 API 认证身份。Android 重载还移除了停止旧内核之前的提前覆盖。

端口预检查与内核正式绑定之间存在系统级竞争窗口；既有启动验证、API 配置核验及 SOCKS 握手验证继续负责发现启动失败并进入既有恢复流程。自动避让不能承诺任何环境下都一定找到空闲端口。

## 本机显示与交付

最终 Release 预览构建号 5005。Android 为 ARM64 / API 24+，APK v2 签名验证通过；macOS 为 Apple Silicon ARM64，本地 ad-hoc 签名。macOS 增量构建出现 App.framework 与外层签名不同步，已重新签名并通过 codesign --verify --deep --strict；ZIP 完整性和两个包 SHA-256 校验通过。

构建副本核对 406 个文件，仅 macOS 应用名称、包标识和单实例隔离所在两份文件有预期差异。交付目录为 artifacts/settings-preview-5005，含安装包、源码清单、构建及回归日志。

本机打开最终 5005，查看四档设置页，实际切换深蓝与纯黑，检查无档的主页、订阅页，以及高档订阅页与日志弹窗。观察范围内无黑块、布局溢出或切换异常。检查完成后恢复原先高档与流动背景，保留用户图片，停在设置页；未建立 VPN 连接。日志诊断显示未连接且尚无运行配置，是该测试预览数据的状态，不作为连接测试成功证据。

本轮未新增 Android/Windows 实机显示、低端 GPU、帧率或功耗测试，也未对每个页面与四档进行完整实机笛卡尔组合验收。跨页面档位传播和端口冲突主要由共享代码审查与回归覆盖；不能将本机观察替代全部设备保证。代码尚未提交、推送或正式发布。
