## 6. 问题与修复建议

1. **账号统计运行期间间歇性隐藏（需要进一步定位）**：冷启动与后续若干状态可见已用流量、在线设备，另一些连接期间两张卡片消失，之后重现。所以不是打包遗漏编译配置。`account_usage_controller.dart` 的失败/过期处理清空统计，客户端请求失败没有足够的脱敏原因可供唯一归因；目前不能断言是 IPv6 或本轮核心改动导致。建议补充脱敏失败类型/状态，明确失败时的展示策略，再复测；本轮未修改代码、未声称修复。
2. **安装器受继承的 PowerShell 模块路径影响（环境问题，有加固价值）**：第一次静默升级在写入程序文件前返回 7，事务 Begin 无法识别 `Get-FileHash`；原安装未被覆盖。将该子进程环境的 PSModulePath 限定为 Windows PowerShell 模块目录后，完全相同的安装器退出 0，核心与载荷验证通过。建议安装器显式初始化 PS5.1 必需模块并保持清晰诊断；没有修改全局环境，也没有卸载用户客户端。

本轮启动可靠性问题未复现，不建议无证据修改其他平台策略。剩余未测项仍需补验后才能作更全面结论。
