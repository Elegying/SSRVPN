# 渲染优化预览交付（2026-09-14）

## 范围

按 Apple Design 技术分析后的用户授权实施，保留 Flutter 三端架构与现有画质。没有引入 macOS 26 专属原生玻璃，也没有提高最低系统版本。

预览包包含当前工作区此前尚未交付的背景压暗合成、玻璃图层复用、固定画质取消逐帧自适应统计、文字布局缓存、流量数值不变时跳过重建，以及更新提示不再遮挡底部更新入口。

本次新增：玻璃截图调度在入队前检查材质是否启用和应用生命周期。轻量模式、高对比度和后台不再为背景重绘排入无效截图回调；执行回调时仍再次检查状态，防止入队后进入后台。恢复前台及材质重新启用仍读取最新背景。新增调度测试核对无效回调计数与恢复后实际像素，既有动画、尺寸变化、纹理释放测试继续保留。

不改变分辨率、背景轨迹、动画帧率、模糊和透明度参数。本轮没有修改后原设备 A/B 性能数据，不能据此宣称 CPU/GPU 降低百分比或所有旧设备卡顿已消失。
