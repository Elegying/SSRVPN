# SSRVPN 实机资源测试（2026-09-14）

## 测试包与范围

- 本次工作区代码构建，界面版本仍为 5.0.1，**不是此前发布的原版 5.0.1 安装包**。
- 基线提交：87ec8ace0a294848eea6620e6faec3549e94d3ba，包含当前未提交修改。构建使用 Flutter 3.44.1 Release，开启 SSRVPN_FRAME_DIAGNOSTICS。
- Android 包名 com.ssrvpn.android.preview；macOS 标识 com.ssrvpn.ssrvpnClient.preview，应用名 SSRVPN Preview。macOS 测试源码副本额外隔离单实例锁，不改正式项目对应逻辑。
- 两端预览版与正式版并存，未覆盖正式版数据。测试订阅含 200 条 localhost 虚构节点，仅用于 UI，不可作为可用 VPN 节点。没有建立 VPN 连接，未测加解密和流量转发负载。正常导入可能触发客户端自身的节点探测，数据包含该正常后台工作。
- 手机：2509FPN0BC，Android 17，可见内存约 14.7 GiB，1200×2608 像素，采样时应用报告约 60 Hz；USB 接入并充电。
- Mac：Apple M1，8 GiB 内存，测试窗口约 482×795 逻辑像素，应用报告 60 Hz。本机其他应用仍运行，存在压缩内存和交换活动，不是专用空载实验环境。

## Android

每个场景约 31 秒，top 1 秒采样，丢弃第一个 CPU 点。CPU 按单核满载 100% 计，多线程可超过 100%。PSS 为末端快照；GPU 活跃时间来自 dumpsys gpu 中测试 UID 的累计值差分。

| 场景 | CPU 平均 / 峰值 | PSS | GPU 活跃时间 / 墙钟时长 | 驱动报告 GPU 内存 |
| --- | --- | --- | --- | --- |
| 初始首页，动态背景、未连接 | 56.4% / 60.0% | 174.3 MiB | 71.5% | 336.3 MiB |
| 200 节点列表持续滚动 | 98.9% / 108.0% | 228.7 MiB | 81.9% | 418.4 MiB |
| 切到系统桌面后台 | 0.1% / 2.0% | 159.8 MiB | 1.0% | 256.8 MiB |

GPU 活跃时间比例不是 GPU 所有运算单元利用率，也不等于芯片满载百分比。驱动 GPU 内存与 PSS 有口径和共享关系，**不可直接相加**。后台样本包含切换后的短暂收尾。

首页稳定帧诊断窗口约 60 FPS，build P95 约 2.8–2.9 ms、raster P95 约 2.0 ms；原始窗口见 android-frames.log。不能把 raster 时间当作完整 GPU 执行时间，也不能将部分稳定窗口推广为所有场景零掉帧。

android-home-repeat 样本未确认成功返回首页，仍表现为后台，作废，不用于首页结论。

## macOS

CPU 使用 top 单核 100% 口径；内存使用 footprint 工具报告的 MB。它与 Android PSS 口径不同，不作简单横向排名。

| 场景 | CPU 平均 / 峰值 | 内存 footprint | 备注 |
| --- | --- | --- | --- |
| 初始首页 | 16.7% / 18.6% | 147 MB | 同时运行轻量 Activity Monitor 采样 |
| 200 节点列表连续滚动，最终复测 | 41.2% / 51.2% | 243 MB | 已结束 Metal 跟踪器，无该跟踪器干扰 |
| 导入并滚动后的首页，最终复测 | 21.3% / 24.1% | 213 MB | 同样无 Metal 跟踪器干扰 |
| 隐藏到后台 | 0.0% / 0.0% | 161 MB | 此场景采集早于最终滚动复测 |

首次列表 CPU 27.2%、footprint 194 MB 的数据受到同时运行的 Metal 跟踪处理干扰，不用作最终列表结果。场景强度与缓存状态也不完全相同，不把前后差异解释为补丁性能变化。

首页稳定窗口约 60 FPS，raster P95 约 0.9–1.4 ms；详细窗口见 macos-direct.log。初始首页 footprint 中 IOAccelerator (graphics) 约 32 MB、IOSurface 约 18 MB；最终滚动约 39 MB 和 24 MB。这些是图形相关内存类别，**不是 GPU 利用率，也不是全部 GPU 内存**。

### macOS GPU 指标未完成

- powermetrics 的进程 GPU 采样需要管理员权限，本机 sudo 非交互尝试返回“需要密码”。未索取或读取密码，未修改系统权限。
- Instruments Activity Monitor 成功记录，但进程表不含 GPU 利用率。
- Metal System Trace 录制 15 秒后长时间无法完成，近六分钟仍未生成可导出结果。中断及终止该测试跟踪器后补测 CPU；保留失败日志，清理约 2.6 GB 不可用临时跟踪。
- 因此本轮 **未测得 macOS 客户端 GPU 占用率**。后续需要管理员授权的进程 GPU 采样，或可正常完成的 Metal 跟踪环境；不能用全机 GPU 利用率或 Flutter raster 耗时冒充此指标。

## 结论与限制

1. 当前测试手机能维持约 60 FPS，但动态首页已产生明显 CPU/GPU 工作，流畅不代表低负载。前台背景和玻璃渲染值得继续分离测量。
2. 两端切后台后的 CPU 接近零，本次未观察到 UI 动画持续高负载运行。
3. macOS 列表滚动后内存比初始首页更高，可能包含渲染缓存与已加载数据；短测不足以认定泄漏或证明无泄漏，需要重复导航及长时间稳定性测试。
4. 未测 Android 9、Windows 10 或弱 GPU，不能代表此前反馈设备已修复。没有原版 5.0.1 同条件对照，不能声称性能提升百分比。
5. 测试包开启轻量帧诊断，有少量采样开销；CPU 结果包含真实客户端的正常后台活动。
6. 本次 UI 采样完成后已关闭测试进程、临时 HTTP 服务和 USB 端口转发。正式客户端未被替换。测试版中保留虚构订阅，后续实际使用需导入自己的订阅。
