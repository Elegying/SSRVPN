# 发布前功能复审

日期：2026-09-14。范围：当前工作区候选代码，重点是稳定性、失败恢复和交互反馈。本文不代表新版本已经发布或实机验收完成。

## 本轮修复

1. **过期桌面重载误断新连接。** 订阅重载进入连接队列后，用户可能已经断开并重新连接。原流程出队后先 stop，再由连接编排检查代际，旧任务会关闭新连接。现在在 stop 前同时检查连接意图与订阅版本，过期任务直接退出。macOS、Windows 共用这段首页实现。真实首页组件测试在修复前确认出现不应发生的 stop，修复后验证新连接保留；另覆盖两次订阅更新排队时只重载最新配置。
2. **自动重载启动失败没有错误提示。** 连接编排返回启动失败时，首页原先将错误置空。现在沿用已有 AppFailure 文案转换，显示失败原因；成功仍清除旧错误。新增真实首页组件测试，验证失败后显示错误、退出连接意图，不误报连接成功。
3. **已取消订阅步骤遗漏资源释放。** 调用者已创建 Future，但等待器进入时刷新已取消或期限已耗尽，原流程只接管迟到异常，没有执行 onAbort。现在仍执行该步清理，并保留原取消/超时结果。新增两个测试，覆盖清理回调抛错、源 Future 迟到失败和重复取消，确保只清理一次。

本轮未添加依赖、后台轮询、额外外部探测或新的订阅访问限制。

## 发布前仍需闭环

**新规则实际启用失败后的自动回退仍未实现，应在本次独立规则更新功能正式发布前闭环。** 当前下载失败保旧、文件校验失败保旧和保守内置规则，不应被描述成“启动失败自动回退上一版”。下载激活会更新磁盘清单，下一次启动可能直接读到新快照；当前没有独立的“已成功启动版本”记录及三端一致的运行失败回退确认。

回退验收至少应覆盖：新版本导致规则加载失败时恢复已知可用版本；进程退出后仍能恢复；坏版本不反复尝试；取消连接不触发重连；节点不可达、VPN 权限拒绝和端口冲突不误判为规则错误；Android 应用排除名单与内核规则回退到同一快照，磁贴恢复配置保持一致。

三端最终安装包还需在同一候选版本上实测首次启动、覆盖安装保留订阅/设置、首次授权与拒绝、快速连接取消重连、Wi-Fi/蜂窝或网络切换、锁屏/休眠恢复、断开后网络恢复。该部分不能用 macOS 上运行 Windows Flutter 测试代替，也不能用先前版本验收代替。
