# SSRVPN 5.0.3 发版前审查

## 范围与版本

本次审查覆盖从 v5.0.2（62d4f43）之后全部设置页未提交改动，准备三端一致的 5.0.3+5003。Android 5004/5005/5006 与 macOS 5004/5005 均为不同应用标识的本地预览；它们的构建号不代表正式发布。

## 修改与复核

- 三页导航：Android PageView 与桌面 IndexedStack 均增加设置页，保持隐藏页面活动状态隔离；弹窗位于外观作用域内。
- 外观持久化：三端设置队列先写入候选，再发布新值，失败保留旧值；并发端口与外观修改不会互相覆盖。旧版本缺少外观字段时保留设备默认档位。
- 材质与背景：四档统一解析；无/低不运行玻璃模糊、折射捕获及连接装饰光晕，中档校准二维材质参数。静态颜色和图片不挂载流动背景。深蓝与纯黑已加入，图片说明增加间距。
- 图片导入：JPG/PNG/WebP 静态图片，输入 20 MB、4000 万像素边界，保存最长边 2048 像素的本地 PNG 副本；取消、失败保留旧背景，不删除用户原图。替换成功仅清理应用拥有的旧背景副本。
- Android 图片选择：官方 Android Photo Picker，系统中断后的结果仅在用户再次点击时恢复，并继续预览确认；旧系统无照片选择器时可能回退文档选择器。APK 权限与上一预览版本一致，没有新增相册或存储读取权限。
- 端口与连接：保存首选端口下次在应用内连接生效，临时避让不覆盖首选端口；三个运行端口互斥。规则/模式编辑保留当前运行端口和 API 身份，停止旧核心前不提前覆盖。端口检查到正式绑定之间仍可能有系统竞争，依靠既有启动和握手验证进入失败恢复。
- 更新与日志：复用原检查、下载、诊断流程；手动检查在页内显示结果，发现更新发布底部入口。启动时的自动更新触发条件保持原逻辑。
- 构建：新增依赖固定于 lockfile；Android 新增 80 个 Gradle 依赖文件与官方仓库独立核对，原有校验锁定保留。正式 macOS 打包脚本会刷新并严格检查 ad-hoc 签名。

## 异常记录

- 5005 回归曾在并行构建时出现 macOS 订阅刷新 5 秒等待超时。构建结束后主页整组 41 项通过，未放宽超时或断言。
- 本次首次 make verify 在本地真实内核分流测试的首个直连样例返回 502。原代码独立复跑 rule/global/fallback/recovered 四组全部通过，之后重新执行完整验证。该首次失败保留在本地日志，不以修改规则或跳过检查处理。
- 预览 macOS 增量编译曾留下 App.framework 与外层签名不同步，已重新签名并严格验证；正式打包已有刷新签名步骤。
