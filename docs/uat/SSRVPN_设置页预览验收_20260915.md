# 设置页预览验收（2026-09-15）

## 交付范围

Android、macOS、Windows 共用新增设置页，位于订阅页右侧。

- 液态玻璃：无、低、中、高。未手动选择的旧安装继续使用设备默认档位；用户选择同时作用于应用表面与玻璃库控件，不重新创建导航或表单状态。
- 背景：原有流动背景，以及蓝、灰、墨绿、橙、黄五种纯色，以色块选择。纯色与自定义图片不启动流动背景动画。
- 自定义背景图：原生文件选择、预览确认、应用目录保存。支持 JPG、PNG、WebP 静态图片，输入上限 20 MB、4000 万像素，保存副本最长边为 2048 像素。适度压暗以保持文字可读；高对比度模式进一步压暗。
- 图片导入、解码、持久化失败或用户取消时，保留旧背景；更换成功后仅清理应用自己保存的旧副本，不删除用户原图。原图移走后已保存的背景仍可使用。
- 自定义代理混合端口：1024–65535，拒绝与 SOCKS、控制端口重复；保存后下次在应用内连接或重连生效。显示当前实际运行端口，保留既有端口占用自动调整。
- 检查更新：检查中防重复点击；最新、失败、发现更新均在页内反馈。发现新版本后沿用底部更新入口及原有下载、验证、安装流程。
- 运行日志：复用现有诊断中心，包括中文诊断结果、历史记录与脱敏明细。
