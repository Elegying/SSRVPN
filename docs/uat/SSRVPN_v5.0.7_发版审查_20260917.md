# SSRVPN 5.0.7 发版审查（2026-09-17）

## 范围与状态

基线为 main `1f09a12`，候选版本 `5.0.7+5007`。此次审查覆盖所有待发布修改；
发布、远端构建与下载验收结果需以对应 GitHub 工作流和 Release 为准。

## 主要变化与审查结论

- 本地核心健康检查同时要求连续失败和观察时长；恢复响应即清零，暂停后重新观察。
  外部网络探测失败不作为停止核心依据；真实核心退出沿用已有有限恢复预算。
- 订阅失败按实际异常类型给出中文原因，技术编号与用户文案分离，展示与日志沿用脱敏链路。
- 取消自动全量测速，支持当前分组与跨组多选，停止只取消后续排队探测；新旧批次计时器隔离。
- 当前节点与链式依赖配置签名未变化时不重连；保留运行节点快照，选择新增或变更节点仍加载最新配置。
- 每个订阅卡片右下角支持独立刷新，复用服务队列、缓存合并、超时和取消机制；其他订阅缓存不丢失。
- 节点选择页测速／卡片逻辑提取为同库私有支持文件；桌面节点编辑菜单移入已有弹窗支持文件。
  不改变连接事务顺序，不增加依赖，不提高原有结构上限。
- Mac 本地构建入口自动携带账户统计配置，防止遗漏编译配置。

## 验证证据

- 针对性测试：共享服务／控制器／界面 110 项通过；额外目标订阅隔离与取消 1 项通过。
- 按指定位置调整按钮后，共享界面 43 项、macOS 订阅页 5 项、Windows 订阅页 6 项通过。
- 节点选择组件提取后的共享界面 43 项通过；桌面结构守卫通过。
- 完整 `make verify`、三端原生 CI 和发版构建仍在本轮执行中，不在此预先标记成功。

## 实机范围与限制

- Mac 本地 release 候选已保留数据覆盖安装并正常启动，严格 ad-hoc 签名校验通过；
  订阅页两个独立刷新按钮已从实际窗口确认，右下角布局符合用户指定位置。
- 实机候选升版前仍显示 5.0.6；包含账户统计编译配置，实际统计卡片依赖有效服务端响应。
- 本轮没有重新完成 Android、Windows 真机全流程，不以此前 5.0.6 报告替代新版本证据。
- 本机 Xcode 27 构建使用仓库外 deployment target 12.0 覆盖，未修改项目最低系统版本。
  旧系统与三端正式产物兼容性继续由原有 CI 构建和用户实机范围分别说明。
