## 结论与范围

**部分完成，不能作为全量验收通过或正式发布依据。** 已在 Windows 真机完成候选构建、保留数据升级、部分系统代理/TUN、诊断、背景及恢复验证；修复两个背景功能问题及两个 Windows 换行相关规则工具问题。Windows 测试重跑通过，但共享完整测试仍有失败，剩余界面场景未覆盖。

### Windows 共享 CI 首次复跑暴露的路径问题

`1695db0` 的 Windows 共享测试结果为 1,305 通过、7 跳过、15 失败，不能记录为已全部修好。
除另一测试入口缺少发布器及路径字符串断言差异外，实际更新恢复逻辑也存在缺陷：
扫描目录返回的 Windows 反斜杠路径与调用方混合分隔符的目标路径直接比较，导致漏认
`.previous.*` 备份，转而下载；备份本来可恢复但网络失败时，用户仍无法完成更新。

后续修复在已限定的目标父目录中比较 URI 文件名，保留备份命名、类型、摘要、大小、取消
与不覆盖检查；发布锁也根据规范父目录和文件名生成，避免两种分隔符产生不同锁。
目录列表断言改比 URI，既有并发恢复测试增加不同路径写法，另一个代理下载测试入口
补齐宿主发布器。Mac 本机这两组回归 39 项通过，Windows 宿主复跑仍需新 CI 确认。
