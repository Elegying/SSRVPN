## 修复与优化

| 问题 | 本轮处理 |
| --- | --- |
| 部分国旗缺失，桌面缓存按名称可能串用旧国别 | 三端共用国旗提示解析与后台 IP 查询，按协议/地址/端口摘要缓存，真实 IP 国别优先；同名改地址失效，改名和重连复用 |
| Android 重载失败撤销意图后再校验，错误状态无法发布 | 先确认当前代际再发布失败并撤销意图，清除忙碌状态；用户主动取消优先 |
| macOS 更新前忽略停止错误，可能在清理完成前打开安装包 | 串行等待幂等停止与清理，失败或出现新连接意图时阻止安装入口 |
| Windows 特殊地理选择组可能停在旧节点 | 检测域名统一走 PROXY，删除重复组与失效查询服务 |
| 大订阅在 UI isolate 重复提取、校验、构建运行文本 | 扩展现有可取消短命 worker，合并结果携带运行文本；保留小输入快路径和缓存事务回滚 |
| macOS 200 ms 守护轮询，Android 探测重复创建线程 | macOS 改为 1 秒可取消等待；Android 单个有界 worker，超时或中断不释放仍在运行的 JNI 占用 |
| Prepare 与 Release 重复重建相同核心 | main CI 保留规范源码重建；下游校验精确 main CI、任务、artifact 身份及摘要后复用，缺失/过期才回退 |
| 依赖更新混合固定 SDK 和构建工具链 | 增加前置锁文件解析检查，SDK 绑定包与 Android 工具链分别分组；未直接升级或合并旧不兼容 PR |
| 正式发布状态与操作手册滞后 | 补记正式 v4.0.35，发布入口统一到 Prepare Release；保留历史实机证据原始版本 |

## 国旗后台行为

- 名称、emoji、有效地区元数据用于首次提示。连接稳定 15 秒后，以最多两个并发任务解析
  节点服务器真实 IP，再通过随客户端打包的 GeoIP 数据库查国家；数据库解压与初始化放入后台 isolate。
- 域名解析通过当前本地 HTTP 代理访问 HTTPS DNS，不切换节点，不绑定物理网卡绕过代理，
  不把国别任务加入延迟测试链路；正在连接、测速、恢复或断开时取消请求。
- DNS 请求有总时间、响应大小、答案条数与 CNAME 关联约束；拒绝私网、保留地址及 fake-IP。
  国别解析不逐 IP 请求第三方 Geo 服务。结果表示节点服务器 IP 所在国家，不承诺等于代理出口国家。
- 三端共用核心在线切换边界；手动切换、自动恢复和配置重载中的选节点操作立即暂停国别查询，
  无论切换成功或失败，结束后都重新等待稳定期，不改变既有连接意图代际。
- 成功结果持久缓存，未改变的端点后续无需再次查询；缓存文件只保存端点 SHA-256 和国别，
  不含 IP、节点名称、凭据或订阅地址。缓存有大小/数量上限，损坏或写入失败不影响连接。
- 失败保留已有提示，未知节点继续显示地球，不编造国家；失败不会永久缓存，在后续稳定会话可重试。
  取消或旧会话迟到结果不更新当前节点。
