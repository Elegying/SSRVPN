# 规则与连接全链路审查

日期：2026-09-14。范围：独立规则仓库、手动规则持久化、三端规则下载与激活、连接及重载流程。以安卓应用名单最高优先级为准。

## 已修复的问题

| 问题与触发条件 | 修复及验证方式 |
| --- | --- |
| 同一域名以 URL、大小写、末尾点等不同形式分别存入代理和直连；桌面保存绕过冲突清理 | 按规范主机键清理对侧，IPv6 旧配置按地址字节识别同目标；桌面串行事务同时写两份列表。回归覆盖持久化及同目标反向保存。父域/子域重叠仍保留代理优先。 |
| 后台更新提前改变内存中的应用名单与规则目录 | 下载完成仅暂存待启用版本；prepareForStart 校验完整快照后同步切换名单与目录，中间无异步间隙。验证当前连接仍生成旧版本配置，重连才整体使用新版。 |
| 重载未成功但旧核心仍在运行，提示新规则已生效 | 重载返回实际成功状态；Android 和共享桌面界面依返回值提示。注入停止失败，确认保存成功但重载失败，不显示实时生效。 |
| 清空应用名单后发布或客户端拒绝空数据 | 仅应用名单允许零条目；域名/IP 数据仍禁止为空。验证空名单发布、客户端接收以及原生显式空元数据不恢复旧名单。 |
| 国内关键域名误入代理列表，仅检查直连表无法发现 | 发布前检查百度、QQ、淘宝等样本不被任何代理集合匹配；支持通配匹配并拒绝纯通配符规则。注入冲突确认旧版本不变。样本检查不等于全网正确性证明。 |
| 发布中断可能留下半写快照或混合 latest 文件 | 临时目录完整构建后提交不可变快照，逐文件原子替换 latest，版本索引最后提交；旧版本依据索引及快照摘要读取。故障注入后确认无半份新快照且可重试。 |
| 版本数字过长或前导零造成跨语言兼容风险 | 发布端和客户端统一三段非负版本格式与长度限制；拒绝非法版本及组件降级。 |
| 短名单打开手动规则弹窗可能越界；IPv6 输入可保存但内核拒绝 | 弹窗先补齐输入槽位，IPv6 字面地址明确拒绝；旧数据仍可读且服从 IPv6 防泄漏规则。修正优先级文案和产品契约。 |
| 大型本地规则校验在界面线程执行 | 将缓存及内置规则的重校验移入 isolate，避免在 UI 线程解析大规则列表；性能收益仍需低端实机测量。 |
| 排队发布作业基于旧事件提交构建 | 工作流检出当前 main，公钥变化也触发检查；并发编辑导致推送冲突时作业失败保留远端，不强推。 |

## 继续核对的保护边界

- 订阅仅提取节点，丢弃上游规则、DNS、组和脚本等配置；合成恶意订阅与大型订阅均有隔离测试。
- 先验签版本索引，再校验不可变快照摘要、每个文件大小/哈希/数量/语法和组件版本。失败保留原版本；无未签名网络 provider 回退。
- 每次进程首次成功连接两分钟后检查一次，断开取消，不轮询、不重试，不主动断线应用；桌面不下载安卓名单。
- 连接前准备配置，核心及认证 API 就绪后检查全部规则 provider，结合系统代理/TUN 状态判定连接成功；切换/断开使用连接意图与串行事务避免旧结果覆盖新意图。
- 安卓国内应用系统排除；国外应用识别成功时优先代理；浏览器、共享 UID、查询失败回到目标规则。进入隧道的 IPv6 拒绝，系统排除应用使用系统网络。

## 必须保留的边界

1. 安卓磁贴冷启动与原生进程恢复复用上次受保护的完整连接配置；后台新快照需经过 App 生成下一次连接配置后才进入磁贴快照。这样不会混用新旧名单，但不能承诺未启动 App 的磁贴立即采用新规则。
2. 本机 Flutter 测试不等于 Android/Windows 实机网络测试。仍需覆盖 Android 10 以下、厂商系统、分身/共享 UID、应用安装卸载、Wi-Fi/蜂窝切换、VPN 权限拒绝、休眠和用户快速取消连接。
3. 当前保留历史完整规则快照，避免删除核心仍使用的文件；长期更新会增加磁盘占用。后续回收需在安全时机保留当前及回退版本。
4. 成熟规则源与关键域名样本不能证明所有目标在所有运营商都分流正确。签名证明来源和完整性，不证明名单本身永远正确；修正应发布更高版本，禁止改写旧快照。
5. 主项目改动尚未提交、合并或发版。公开规则仓库的发布工具修复单独上线，不能据此声称客户端已升级。
