# SSRVPN 5.0.0 UI 审查与性能验证

日期：2026-09-13。目标版本：三端统一 `5.0.0+5000`。

用户已确认 Windows、macOS、Android 液态玻璃版本验收通过，并授权在保持当前视觉效果的前提下优化、审查及正式发布。本报告记录发布候选的源代码与本地验证证据；正式发布结果以对应 GitHub Actions、Release 及公开下载校验为准。

## 审查范围与上游核对

- 以 Liquid Glass Widgets 1.4.4 的原始包、官方仓库与当前 vendored 实现作差异核对，检查实际使用的渲染器、shader、背景捕获、质量适配和资源释放路径。没有升级到未经本次验收的依赖版本。
- 检查本版本全部 UI 入口：首页连接按钮、节点卡片、速率和配额卡片、底部导航、订阅与节点编辑、节点列表和模式选择器、教程、关于、诊断日志及其他弹窗；同时检查共享主题、字体、桌面标题栏、滚动与页面过渡。
- 对快速重复开关弹窗、首次捕获、页面平移、尺寸变化、前后台切换、渲染器重建和表单状态保持进行对抗性检查。
- 核对 MIT 授权及 renderer、spring utility 的来源声明，补丁说明保留在 `packages/liquid_glass_widgets/SSRVPN_PATCHES.md`。

## 本轮发现及修复

| 问题 | 影响 | 修复 |
| --- | --- | --- |
| 背景采样存在独立逐帧循环 | 壁纸静止时仍申请 GPU 纹理，前景更新也可能产生多余工作 | 改为背景实际绘制后采样；只移动页面时复用纹理并更新采样原点 |
| 静止背景中的内层绘制边界隔离了图片更新 | 减少动态效果或壁纸暂停时，迟到的图片绘制可能未更新玻璃纹理 | 复用外层捕获边界，移除多余的内层边界；对抗测试使用实际漂移组件复现后验证修复，仍保留 120 次前景更新零新增采样 |
| 纹理通知经 InheritedNotifier 广播 | 所有依赖玻璃表面跟随背景更新重建 | 仅采样层订阅纹理，复用已有内容子树 |
| 上游 shader builder 按列表对象身份判断变更 | 同样的 shader key 在普通重建时反复创建 FragmentShader，旧实例未明确释放 | 改为内容比较，复用实例；切换资源和卸载时释放；拒绝过期异步加载结果 |
| 已布局但尚未绘制时尝试捕获 | 首次显示或尺寸变化时有机会读取尚未准备好的边界 | 记录背景绘制就绪状态，仅在完成绘制后捕获 |
| 首帧无纹理时更换渲染组件结构 | 表单或有状态内容可能重新挂载，也可能短暂进入实时 backdrop 路径 | 保持同一渲染层；等待首张纹理期间保留内容，不进入该 fallback 路径 |
| 应用后台继续轮询刷新率 | 无可见收益的后台平台调用 | 后台暂停轮询，恢复前台重读，并防止请求重叠 |
| 背景动画在 inactive 状态继续，而玻璃采样已暂停 | 失去活动状态时画面与纹理可能不同步，并继续消耗绘制资源 | 统一仅在 resumed 状态运行动画与采样；对抗测试先复现再验证暂停及连续恢复 |
| 弹窗退出期间仍接受点击 | 快速重复点击可再次触发退出中的操作 | 反向动画阶段禁止指针交互 |
| UI 测试未推进退出动画时钟 | 等待 route.completed 的测试超时，掩盖真实回归 | 显式推进 Flutter 测试时钟，同时保留真实异步任务和业务结果断言 |
| 字体源未进入覆盖率清单 | 测试通过但来源完整性门禁失败 | 将字体配置加入覆盖率源清单 |

## 视觉与业务保持

- 保留当前 premium 的折射、厚度、高光、饱和度和模糊参数；背景采样继续使用实际设备像素比，没有降低采样分辨率。
- 保留动态背景、连续往返漂移及旧背景回退资源；保留已验收页面过渡和桌面融合标题栏。
- 桌面及适用安卓设备仍优先 premium；运行时性能适配策略不通过本轮调整门槛或主动降档来制造优化结果。
- 未改变连接、TUN、分流、订阅处理、出口国旗缓存及“私家车”延迟显示策略。

## 可重复验证证据

| 验证 | 结果 |
| --- | --- |
| 共享包全量测试 | 1146 项通过 |
| 共享包覆盖率 | 87.53%（8914/10184），门槛 65% |
| 三端生产 lib/test、共享层及 vendored renderer 静态分析 | 无问题 |
| 同一 shader key 连续 120 次重建 | 复用同一个 FragmentShader；资源变化及卸载后确认释放 |
| 壁纸静止、连续 120 次前景更新 | 不增加背景采样次数，复用原纹理 |
| 页面平移、窗口尺寸变化、暂停及恢复 | 平移只更新原点；尺寸变化重新采样；暂停不采样；恢复补采样 |
| 纹理到达及多阶段 materialize | 内容状态与输入文字保持，不重新挂载 |
| 安卓更新服务测试 | 22 项通过，包含安装、失败、超时与清理路径 |
| 版本、格式、文档及产品结构检查 | 本地通过 |

测试证明资源复用和生命周期行为，不等同于所有手机均能稳定达到 120 FPS。实际刷新率仍由屏幕能力、系统设置、温控、省电策略和 GPU 负载共同决定。

## 实机与发布边界

- 用户在本轮开始前已完成三端视觉验收。
- 本轮 Android 固定 premium 的诊断候选已成功构建并安装，用于排除自动降档对性能判断的干扰。安装后测试手机处于息屏状态，当前尚未取得有效新增帧耗时数据；不能把该状态记录为帧率验证通过。诊断开关不进入正式线上构建。
- 本轮没有进行 macOS 断网测试，没有清除设备数据。
- 合并与正式发布必须通过受保护分支和精确主分支提交的检查；通过 Prepare Release 创建 `v5.0.0`，由正式工作流构建和发布三端产物，再校验公开下载与哈希。

本地审查未发现尚未处理、足以阻止此候选进入线上门禁的 UI 问题。首次采样和窗口/路由边界仍需结合实际 GPU 表现持续观察，不能用测试数量替代实机证据。
