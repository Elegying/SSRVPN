## 签名约定更正

依照现有发布清单，Android 使用既有自签名发布 keystore；macOS 采用 ad-hoc 且未公证，Windows 未代码签名。免费桌面分发是项目既定选择，缺少付费桌面证书不是阻塞项。上一份审查报告对此表达不准确，已补充更正。

本地 Android Debug 证书不能替代正式升级签名；正式产物仍由既有工作流打包、校验并生成来源证明。上轮本地 5.0.1 审查包不代表本轮 5.0.2 候选。
