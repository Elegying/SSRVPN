# 纹理回收与帧诊断优化（2026-09-14）

## 修改与审查结论

1. 共享玻璃截图：材质停用后延后发布空纹理，等消费者完成下一帧绘制再释放旧图片。合并图片退休逻辑，避免释放仍被绘制使用的资源。快速重启时重新检查启用状态，已重新启用则保留当前纹理。没有对短暂失焦或所有缓存做无条件清空。
2. 原生刷新率缺失回退：收到 MissingPluginException 后停止重复调用该方法，后续使用 Flutter 显示信息。暂时性的 PlatformException 不会永久关闭轮询；支持接口的平台仍使用原有刷新率跟踪。
3. 可选帧诊断：增加构建与光栅 P99、最大耗时、窗口内最长连续超预算帧段；目标预算仍遵循设备帧率策略。暂停时注销统计并清空采样，恢复后重新开始。监听器启停为幂等操作。

普通运行不开启逐帧诊断。帧统计反映 Flutter 准备帧的工作，不是点击到屏幕显示的完整延迟；连续帧段按当前诊断窗口计算，不跨窗口累计。

## 审查边界

保留背景、透明度、模糊、分辨率和动画参数。纹理回收是资源生命周期优化，不是已证实的泄漏修复。没有新的原手机 CPU/GPU A/B 数据，不能量化实机收益。

主动内存压力回收、完整原生显示事件桥接、减少透明度桥接和动画速度曲线调整暂不扩大实施；当前变更已有确定的状态和回归检查，以上方向需要各自的平台与视觉验证。
