# 订阅更新保留未变化的连接

- Android、macOS、Windows 在订阅版本变化时，对比当前节点及其链式代理依赖的连接配置。
- 节点身份、协议、地址、端口、认证及扩展连接参数参与比较；分组、延迟、在线展示和测速时间不参与。
- 当前连接未变化时只更新本地订阅和节点列表，不停止核心、不重新请求 TUN 授权。
- 保留当前运行节点快照，后续选择新增或连接参数已变化的节点时，使用最新订阅重载连接。
- 桌面同步更新自动恢复计划的订阅版本，避免保留连接后因旧版本检查而失去恢复能力。
- 尚未确认当前运行节点、当前节点或依赖变化时仍沿用现有更新流程；网络设置修改仍正常重载。
- 旧版本排队回调不能触发较新订阅的额外重载。连接配置比较值可能含凭据，禁止写入日志。

本轮为本地代码与自动化验证，未安装候选包或发布。

验证结果：共享节点控制器 9 项、Android 首页 32 项、macOS 首页 45 项、Windows 首页 23 项通过。
四工作区静态分析、格式、ShellCheck 和 `git diff --check` 通过。
