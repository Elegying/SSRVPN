# #246：用户控制测速范围与停止

反馈来源：https://github.com/Elegying/SSRVPN/issues/246

## 定位与修改

- Android 和共享桌面首页在启动、订阅快照变化、连接完成等路径自动测速全部节点，已移除这些自动触发点。
- 节点页复用订阅筛选：闪电按钮只测试当前分组；多选模式可跨分组勾选本次要测试的节点。
- 批量测速不再占用节点选择的动作锁。提供停止按钮，立即使批次失效、保留已接收结果并停止后续排队。
- 已发出的探测沿用既有超时结束，期间显示“正在结束当前检测”；不宣称所有底层套接字立即中止。
- 旧任务结束时仅可取消自己批次的刷新计时器，避免影响新的测速任务。
- 测速取消不调用 VPN 停止或修改 TUN 设置。当前范围选择不持久化为自定义集合。

## 能力边界

这里测量的是连接延迟。现有排序可用于按延迟比较节点，不等于下载速度、代理可用性或长期稳定性评分。
本次不自动切换节点，也未新增耗流量的带宽测试或伪造综合评分。
