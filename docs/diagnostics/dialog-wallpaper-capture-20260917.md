# 诊断弹窗背景错位：2026-09-17

状态：完成本地候选安装后的增量验收；过程中发现并补修嵌套形状组越界，详见下文。

## 反馈与定位

用户提供 macOS 5.0.8 截图：展开运行日志的技术详情时出现额外卡片轮廓，
随窗口宽度变化移动。完整截图显示轮廓与后方设置卡片相似，不能仅归因为文字溢出。
这与日志中外部网络观察失败是两个问题。

源码存在明确的背景来源缺口：`SsrvpnAppBackdrop` 在页面子树中提供仅含壁纸的
`SsrvpnGlassFrame`，`showSsrvpnGlassDialog` 创建的独立路由不能自然继承该来源。
高档玻璃在缺少来源时退回实时背景取样，可能读取已绘制的设置卡片和嵌套表面。
截图的具体 GPU 成因仍需安装候选实测确认，不以组件测试代替。

## 修复

弹窗创建前取得页面的共享纹理来源，传入弹窗子树；嵌套弹窗继续共享同一来源。
复用现有材质、清晰度、取样坐标和纹理生命周期，不新增逐卡片截图或常驻刷新循环。
主页面重绘或窗口尺寸变化后，弹窗订阅最新纹理。
没有共享来源的调用场景保留原有回退行为；低档、无特效的逻辑不变。

## 回归

`diagnostics_dialog_navigation_test.dart` 新增真实背景捕获测试：

- 弹窗与页面使用同一纹理通知源。
- 宽窗口收窄后纹理更新。
- 蓝色壁纸前放置红色前景，捕获像素仍为蓝色，前景不进入纹理。
- 嵌套弹窗继承同一来源。
- 原有重复关闭、过期回调不误退主页测试保留。
